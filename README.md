# The Basque Coast Estuarine Sediment Gene Catalogue (BCES-GC)

Code and processed metadata for the **Basque Coast Estuarine Sediment Gene Catalogue**, a resource for exploring the taxonomic and functional potential of microbial open-reading frames (ORFs) from estuarine and coastal sediments in the Basque coast (Bay of Biscay).

The catalogue accompanies the Scientific Data article:

> https://www.nature.com/articles/s41597-025-06163-6

This repository contains the post-processing scripts used to extract catalogue ORF identifiers, combine annotation tables, clean gene and functional identifiers, calculate catalogue statistics, and explore MAG taxonomy and contig-level similarity.

## About the catalogue

The BCES-GC workflow begins with metagenomic contigs reconstructed for coastal and estuarine sediment samples. Open-reading frames (ORFs) were predicted and functionally annotated, while MAG-level taxonomy was assigned separately.

The data in this repository support the catalogue at several levels:

- **ORF identity:** an identifier list derived from the catalogue FASTA.
- **ORF annotations:** combined SqueezeMeta-format information for genes, KEGG, COG and PFAM identifiers.
- **Taxonomic context:** Bacteria, Archaea, Eukarya, Viral or unclassified assignments.
- **Catalogue summaries:** global counts for ORFs and annotations.
- **Metagenome similarity:** an abundance-based Bray-Curtis matrix for clustering and ordination.
- **MAG taxonomy:** an interactive Krona HTML visualization.

The repository is primarily a data-processing and visualization companion; the large catalogue FASTA, ORF abundance tables and upstream SqueezeMeta outputs are not all stored directly here.

## Catalogue statistics

The catalogue contains **108,315,453 total ORFs**. The taxonomic distribution is:

| Taxonomic assignment | ORFs |
|---|---:|
| Bacteria | 94,798,283 |
| Archaea | 586,358 |
| Eukarya | 754,365 |
| Viral | 36,491 |
| No assigned taxonomy | 12,139,956 |

Functional annotation coverage is:

| Database | Annotated ORFs |
|---|---:|
| KEGG | 63,458,246 |
| COG | 84,898,618 |
| PFAM | 57,044,320 |

The summary data are stored in [`R/ORFCatalogueStats.txt`](R/ORFCatalogueStats.txt).

## Workflow

### 1. Extract ORF identifiers

[`Python/GetORFIDs.py`](Python/GetORFIDs.py) reads a catalogue FASTA file and writes every FASTA record identifier to a text file.

```python
python Python/GetORFIDs.py
```

Before running:

- Set `input_fasta` to the catalogue FASTA, such as `GC_250.fna`.
- Set `output_ids` to the desired ORF-ID output file.

The script requires `Biopython`:

```bash
python -m pip install biopython
```

### 2. Format SqueezeMeta ORF tables

[`Python/FormatFilterORF_table.py`](Python/FormatFilterORF_table.py) removes unused columns from a SqueezeMeta-style ORF table and prints a tab-separated table with the fields needed for subsequent merging and cleaning.

```bash
python Python/FormatFilterORF_table.py input_ORF_table.txt > formatted_ORF_table.txt
```

The script accepts the input file as a command-line argument and uses `pandas`.

### 3. Concatenate ORF data tables

[`Python/concat_tables.py`](Python/concat_tables.py) searches for files matching `13.*.txt`, reads each table into a pandas DataFrame, concatenates them and writes `ORF_dataAll.csv`.

```bash
python Python/concat_tables.py
```

Run this script from the directory containing the matching SqueezeMeta `13.*.txt` tables.

### 4. Match annotations to catalogue ORF IDs

[`Python/FilterORFtable_ORFID.py`](Python/FilterORFtable_ORFID.py) reads:

- `ORF_dataAll.csv`, generated by `concat_tables.py`
- `ORF_IDs.txt`, generated by `GetORFIDs.py`

It performs an inner merge on the `ORF ID` field and writes `ORF_datafiltered.csv`, preserving only catalogue ORFs and their corresponding annotation rows.

```bash
python Python/FilterORFtable_ORFID.py
```

### 5. Clean functional annotations

[`Python/CleanFunctionalInfo.py`](Python/CleanFunctionalInfo.py) cleans the filtered annotation table by:

- Removing trailing `*` symbols from KEGG and COG identifiers.
- Splitting multiple gene names and retaining the first annotation.
- Splitting semicolon-separated KEGG and COG identifiers.
- Separating PFAM identifiers from descriptive text.
- Writing the cleaned result to `ORF_InfoClean.txt`.

```bash
python Python/CleanFunctionalInfo.py
```

The script reads `ORF_datafiltered.csv` and writes `ORF_InfoClean.txt` in tab-separated format.

## R analyses and visualizations

### Catalogue annotation summary

[`R/ORFData.R`](R/ORFData.R) reads `R/ORFCatalogueStats.txt` and creates visual summaries of catalogue taxonomy and functional annotation coverage.

The script produces:

- A pie chart of total ORFs by taxonomic assignment.
- Bar plots comparing the percentage of Bacteria, Archaea, Eukarya, Viral and unclassified ORFs that are mapped to KEGG, COG and PFAM.

Run it from the repository root:

```bash
Rscript R/ORFData.R
```

Required R packages:

- `tidyverse`
- `RColorBrewer`
- `ggrepel`
- `scales`

Note: The script currently reads `../ORFCatalogueStats.txt` relative to the R working directory. Open it in R or run it while working in `R/`:

```r
setwd("R")
source("ORFData.R")
```

### Contig-similarity and ordination

[`R/SimkaMinCalc.R`](R/SimkaMinCalc.R) uses the semicolon-separated abundance/Bray-Curtis matrix at [`R/mat_abundance_braycurtis.csv.gz`](R/mat_abundance_braycurtis.csv.gz).

The script:

- Loads the similarity matrix.
- Calculates maximum-distance hierarchical clustering.
- Produces a dendrogram.
- Runs a three-dimensional NMDS using Bray-Curtis distances.
- Generates a two-dimensional ggplot of the NMDS scores.

Required R packages:

- `tidyverse`
- `vegan`
- `ggplot2`
- `ggrepel`
- `RColorBrewer`

Run from `R/`:

```r
setwd("R")
source("SimkaMinCalc.R")
```

The displayed NMDS code in the repository uses `k = 3` and reports that the original run did not converge. Users may need to adjust the seed, number of iterations or trymax value in `metaMDS()` when rerunning it.

## Data processing notes

- The Python scripts assume that upstream SqueezeMeta and catalogue files have already been generated.
- Several scripts use fixed input and output filenames and should be run in the directory containing those files.
- Functional identifiers may contain multiple annotations separated by `*`, `;` or commas. The cleaning scripts retain the first or primary value in selected fields.
- `ORFCatalogueStats.txt` summarizes the catalogue as a whole, not the abundance of individual ORFs.
- The Bray-Curtis matrix and Krona visualization are derived from processed metagenomic or MAG data and may require upstream contig, abundance or taxonomy tables for full reproducibility.

### External upstream tools

The complete catalogue workflow is expected to require tools and databases used for metagenome assembly, ORF prediction and annotation, including SqueezeMeta and its KEGG, COG and PFAM annotation resources. SIMKA or a compatible contig-abundance pipeline was used for the similarity matrix, and Krona Tools was used for the MAG visualization.

## External data not included

The following upstream products are required for full repetition of the complete catalogue workflow and are not represented as standalone files in this repository:

- Raw metagenomic sequencing reads.
- SqueezeMeta output tables.
- Predicted catalogue contigs and protein sequences.
- The complete MAG FASTA collection.
- Individual per-sample ORF abundance tables.
- Database and taxonomy files used by upstream annotation pipelines.
  
This files are available at BioStudies repository accession S-BSST1815 https://www.ebi.ac.uk/biostudies/studies/S-BSST1815
